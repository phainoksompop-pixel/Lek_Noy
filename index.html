Setup

เปิดใช้งานยังไงให้ได้ผลดีที่สุด

อ่านครั้งเดียว ใช้ได้ตลอด

1. Browser

ใช้ Chrome หรือ Edge เท่านั้น (Web Speech API ไม่รองรับใน Firefox/Safari) และต้องต่อ internet เพราะการถอดเสียงประมวลผลที่ Google server

2. ประชุมในห้อง (แบบเจอหน้า)

วางโน้ตบุ๊คกลางโต๊ะ → กด เริ่มบันทึก → ตรวจทาน Transcript ก่อนคัดลอกออกไปใช้งานต่อ แม่นที่สุดถ้าใช้ไมค์ประชุม USB

3. ประชุมออนไลน์ (Zoom / Teams / Meet)

⚠️ ข้อจำกัดจริงที่ต้องรู้: Web Speech API ถอดเสียงได้จาก ไมโครโฟน เท่านั้น — ไม่สามารถถอดจากเสียง Tab ที่แชร์เข้ามาได้โดยตรง (เป็นข้อจำกัดของ Chrome เอง ไม่ใช่ bug ของ tool)

มี 3 ทางออก เรียงตามคุณภาพ:

  • ดีที่สุด — ติดตั้ง virtual audio cable (VB-Cable บน Windows / BlackHole บน Mac) แล้วตั้งเป็น default input → เสียงทุกคนในห้องประชุมออนไลน์วิ่งเข้าไมค์ ระบบถอดได้ครบ
  • ง่ายที่สุด — ถอดหูฟัง เปิดเสียงประชุมออกลำโพง แล้วให้ไมค์โน้ตบุ๊ครับเสียงทั้งห้อง (คุณภาพลดลงบ้าง แต่ใช้ได้จริง)
  • สำรอง — ติ๊ก “จับเสียง Tab/หน้าจอ” เพื่ออัดไฟล์เสียงไว้ แล้วเอาไฟล์ .webm ไปถอดด้วย ASR ที่แม่นกว่า (Whisper / AssemblyAI / Teams transcript) แล้วเอาสคริปต์มาวางที่ Tab 2 → ปุ่ม “วาง Transcript ที่มีอยู่แล้ว”

4. เส้นทางที่แนะนำสำหรับงานลูกค้า

ถ้าประชุมสำคัญ (Workshop / UAT / Steering) ให้ใช้ Teams/Zoom transcript ที่มี speaker แยกมาให้อยู่แล้ว → วางเข้า Tab 2 → ตรวจทานและคัดลอกออกไปทำงานต่อ · จะได้ทั้งความแม่นและความเร็ว

5. ทางลัดคีย์บอร์ด

Ctrl+Space เริ่ม/หยุดบันทึก · Ctrl+S เซฟ session

🔒 ข้อมูลทุกอย่างอยู่ในเครื่องคุณ ไม่มีการอัปโหลดที่ไหน ยกเว้นตอนกด “สรุปด้วย AI” เท่านั้น — สำหรับลูกค้าที่มี NDA เข้ม แนะนำถอดชื่อจริงออกก่อนสรุป
